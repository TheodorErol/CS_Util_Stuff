# CS_Util_Stuff

In this project you can find two folders. 

In each there is another README with more specific instructions. 

You will download both, I recommend using the Numpad one as its the one getting developed first.

**For anyone familiar with Git just clone the repository and pull regulary to keep it up to date.**

**For anyone not familiar with Git: to download just click at the green <> Code Button and select Dowload ZIP.**  
**This means you won't get any new updates and if you want to get any fixes or new content you need to redownload again.**  
**When downloaded extract the .zip file where you want and follow the instructions given in the README of your chosen way (Numpad/Function Keys).**  

If you have a short keyboard without a numpad or don't want new binds on your numpad use the Function keys one (F1, F2...).
